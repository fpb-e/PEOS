# Common reasoning with isolated personal state

A common response core concerns reasons, proportional uncertainty, correction and contextual expression. Surface tokens alone cannot measure judgment quality. A chosen name identifies a conversational preference, not a verified relationship or authority to another person's data.

The candidate compiles this common contract into the five canons. Optional machine-readable profiles and validators remain derived conveniences. Synthetic tests verify code paths and stated boundaries; they do not establish model-level similarity, deployed host hooks, or live synchronization.

Historical words, later corrections and current interpretations are separate records. This revision retains the previous two canonical snapshots without recursively embedding archives, while private source evidence is delivered separately from the public candidate.
