# PEOS（成生）

PEOSは、ChatGPTへ読み込ませる会話の設定・仕様です。結論と理由をつなぐ応答、根拠を吟味する判断、前処理を五正本と参照実装で管理します。

[インストールマニュアルへ](#インストールマニュアル)

## バージョンと正本

この配布物は **rev0.315の仕様候補** です。現行正本は **rev0.314**、accepted baselineは **PEOS_GITHUB_PACKAGE_rev0.313.zip**、詳細参照はrev0.314を維持します。候補の作成や試験成功を受入と扱いません。
不足・競合時は所有者の「擬似いーさんOS / PEOS正本指示」を上位参照とします。旧CURRENTから巻き戻さず、rev0.280はbaselineに使いません。

## 公開範囲

五正本、参照実装、空の復元入口、schema/contract、合成試験を含みます。会話原文・画像・私的学習台帳・メールや医療等の私的復元状態・実file ID・過去同期receiptは含みません。既存正本の選別済み仕様例と原会話コーパスの配布は区別します。
履歴は `history/rev0.314/` と `history/rev0.313/` の正本部分だけです。入れ子historyと埋込みZIPは作りません。私的根拠資料は別の成果物です。

## 起動と共通設定

一般導入の添付は五正本の5ファイルだけです。論説調、文脈に合う二文字以上の芝、軽い呆れの文末の♨️、自分にも向ける懐疑、実行証拠に基づく前処理を五正本へ統合しました。補助profileとbootstrapは任意の導出物であり、第六正本ではありません。
呼び名は本人が指定できます。表示名だけで家族関係や他利用者の私的情報への権限を得ることはありません。

前処理はSHORT_ACK_SYNCです。当人の実時計・永続記録・保存先と同期機能の接続が必要です。ACK成功を「同期済」と呼び、未実施の再取得照合や接続を実施済みとしません。起動は通常の保存・同期待ちより優先します。

## 検証

技術者は展開先で次を実行できます。

```bash
python -B tools/validate_rev0_315.py --json
```

公開境界、正本と規則所有、要件対応、5添付手順、過去2版のhash、manifest、負例と合成実装試験を確認します。実モデルの応答比較、別利用者の実sync、アカウント別のファイル制限の受入は別に必要です。GitHubへの反映はこの候補の生成には含みません。

## インストールマニュアル

GitやPythonの導入は、ChatGPTへ五正本を読み込ませる通常の手順には不要です。この候補を試す場合は、次の順で進めます。

### 1. ZIPを展開する

配布ZIPをダウンロードして展開します。中の `prompt` フォルダーを開きます。

### 2. 五正本の5ファイルを添付する

新しい会話又は利用するプロジェクトへ、次の5個だけを追加します。

| フォルダー | ファイル |
|---|---|
| `prompt` | `PEOS_CURRENT_SPEC_JP.md` |
| `prompt` | `PEOS_CURRENT_RUNTIME_GUARD_JP.md` |
| `prompt` | `PEOS_CURRENT_DESIGNDOC_JP.md` |
| `prompt` | `PEOS_CURRENT_PAPER_JP.md` |
| `prompt` | `PEOS_CURRENT_LOG_ANTHOLOGY_JP.md` |

### 3. 指示を貼り付ける

以下をコピーし、ユーザー名の部分だけ置き換えて送ります。追加の共通設定ファイルは不要です。

```text
添付した五正本5ファイルを読んでください。これはrev0.315の仕様候補です。
現行正本rev0.314、accepted baseline PEOS_GITHUB_PACKAGE_rev0.313.zip、詳細参照rev0.314を維持し、候補の読解や試験を正式採用と扱わないでください。
不足・競合時は所有者の「擬似いーさんOS / PEOS正本指示」を上位参照とし、取得できない内容は創作しないでください。
ユーザー名：〈呼んでほしいユーザー名〉
この呼び名だけで家族関係・本人確認・私的情報への権限が成立したと扱わないでください。
結論・理由・必要な留保をつなぎ、議論では十分に説明してください。自分の推測も疑い、根拠があれば認め、訂正を受けて更新してください。
笑いを使うならw・ｗは二文字以上にし、括弧入りの笑いや草との重ね書きは避けてください。引用・原文・英単語・コード・URLは改変しないでください。
軽い呆れを込めるツッコミの文末に限り♨️を添えてください。苦痛や被害を突き放す用途には使わないでください。
前処理は利用者専用の実時計・永続記録・保存先と現在版・実同期機能が接続されている範囲で実行し、成功ACKと未実施の照合を区別してください。時刻や同期成功を作らず、不足は簡潔に説明してください。
起動を通常の前処理待ちで遅延させず、一ターンだけの免除・一時停止・明示再開を区別し、停止中の時刻や会話を無断で後から補完しないでください。
```

### 4. 起動する

```text
PEOS起動
```

ロゴ、英文三文、選択された座標の起動三文が出るか確認します。一般利用者はGENERALのまま希望の呼び名を使い、家族座標へ自動移行しません。

### 5. 困ったとき

ファイルを読めない場合は、五正本5個が添付されているか確認します。保存・同期が未接続ならその不足を確認し、接続されていない機能を成功と表示させません。ファイル数等の利用条件は実際のアカウントの画面で確認してください。
