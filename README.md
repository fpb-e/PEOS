# PEOS（成生）

PEOSは、ChatGPTへ読み込ませる会話の設定・仕様です。結論と理由をつなぐ応答、根拠を吟味する判断、前処理を五正本と参照実装で管理します。

**[公開用ZIPをダウンロード（rev0.316・約564 KiB）](downloads/PEOS_GITHUB_PACKAGE_rev0.316.zip?raw=true)**

[配布ZIP置き場・チェックサム](downloads/README.md) · [インストールマニュアルへ](#インストールマニュアル)

## バージョンと正本

配布ZIPは **rev0.316作成時の固定スナップショット** です。所有者による現在の指定は、現行正本 **rev0.316**、accepted baseline **PEOS_GITHUB_PACKAGE_rev0.315.zip** です。ZIP内に残る旧CURRENT・候補表記・旧baselineは作成時点の記録として扱い、後続の正本指定を巻き戻しません。読解や試験だけで新しい版を正式採用したとは扱いません。
不足・競合時は所有者の「擬似いーさんOS / PEOS正本指示」を上位参照とします。旧CURRENTから巻き戻さず、rev0.280はbaselineに使いません。

## 公開範囲

五正本、参照実装、空の復元入口、schema/contract、合成試験を含みます。会話原文・画像・私的学習台帳・メールや医療等の私的復元状態・実file ID・過去同期receiptは含みません。既存正本の選別済み仕様例と原会話コーパスの配布は区別します。
履歴は `history/rev0.315/` と `history/rev0.314/` の正本部分だけです。配布ZIPの内部には、入れ子historyや別のZIPを含めません。リポジトリの `downloads/` に公開用ZIPを保存します。私的根拠資料は別の成果物です。

## 起動と共通設定

一般導入では、配布ZIPをそのまま添付し、中の現行五正本を読み込ませます。ZIPを展開・読解できない環境では、五正本の5ファイルを個別に添付します。有効な応答規則を定める正本は、どちらの方法でも同じ五正本です。論説調、文脈に合う二文字以上の芝、軽い呆れの文末の♨️、自分にも向ける懐疑、実行証拠に基づく前処理を五正本へ統合しました。補助profileとbootstrapは任意の導出物であり、第六正本ではありません。
呼び名は本人が指定できます。表示名だけで家族関係や他利用者の私的情報への権限を得ることはありません。

前処理はSHORT_ACK_SYNCです。当人の実時計・永続記録・保存先と同期機能の接続が必要です。ACK成功を「同期済」と呼び、未実施の再取得照合や接続を実施済みとしません。起動は通常の保存・同期待ちより優先します。

## 今回の仕様差分

親密度と冗談の通じやすさを分け、低下条件のAND、自己の冗談への返答の例外、判定保留、原因別の回復、根拠付き訂正への感謝を明確にしました。数値や回復時間は未指定です。
仮定を実際の結果へ変えず、背景補足だけで軽口を撤回しません。25項目のうち事実は私的復元へ、未採用提案は未採用のまま分離しています。公開の参照policyは明示された文脈の条件を評価するコードであり、言葉から心理や親密度を自動採点する機能ではありません。

## 検証

技術者は展開先で次を実行できます。

```bash
python -B tools/validate_rev0_316.py --json
```

公開境界、正本と規則所有、要件対応、5添付手順、過去2版のhash、manifest、負例と合成実装試験を確認します。実モデルの応答比較、別利用者の実sync、アカウント別のファイル制限の受入は別に必要です。GitHubへの反映はこの候補の生成には含みません。

## インストールマニュアル

配布ZIPをそのまま添付する方法から案内します。ZIP内のファイルを展開して本文まで読める環境が対象です。利用者の端末へGitやPythonを導入する必要はありません。ZIPを添付できない、又は中身を読めない場合は、[五正本を個別に添付する方法](#5-zipを読めない場合五正本を個別に添付する)を使います。

### 1. 配布ZIPを保存する

[PEOS_GITHUB_PACKAGE_rev0.316.zip をダウンロード](downloads/PEOS_GITHUB_PACKAGE_rev0.316.zip?raw=true)します。この方法では、利用者が先に展開する必要はありません。

GitHubのファイル画面が表示された場合は、ダウンロードボタン（Download raw file）で保存します。[配布ZIP置き場](downloads/README.md)でファイル名・サイズ・SHA-256を確認できます。「Code → Download ZIP」で取得するリポジトリ全体とは別の配布物です。

このZIPは公開時の118ファイルを固定したものです。ZIP内のREADMEは作成時点の案内であり、最新の導入手順はこのページを参照してください。

### 2. ZIPをそのまま添付する

新しい会話又は利用するプロジェクトへ、保存した `PEOS_GITHUB_PACKAGE_rev0.316.zip` を追加します。

添付の完了だけでは、ZIP内の本文を読めたことは確認できません。次の取り込み指示で対象の五正本を選び、本文の読解を確認します。

### 3. 取り込み指示を送る

以下をコピーし、ユーザー名の部分だけ置き換えて送ります。追加の共通設定ファイルは不要です。

```text
添付したPEOS_GITHUB_PACKAGE_rev0.316.zipを開いてください。
パッケージルート直下のprompt/にある、次の現行五正本の本文を読んで、起動・応答の規則として適用してください。
prompt/PEOS_CURRENT_SPEC_JP.md
prompt/PEOS_CURRENT_RUNTIME_GUARD_JP.md
prompt/PEOS_CURRENT_DESIGNDOC_JP.md
prompt/PEOS_CURRENT_PAPER_JP.md
prompt/PEOS_CURRENT_LOG_ANTHOLOGY_JP.md
history/内の旧版や合成試験用データを、現行の起動・応答規則へ置き換えないでください。補助ファイルは役割に応じた参考資料として扱ってください。
所有者の現在の指定は現行正本rev0.316、accepted baseline PEOS_GITHUB_PACKAGE_rev0.315.zipです。ZIP内の旧CURRENT・候補表記・旧baselineから巻き戻さないでください。読解や試験だけで新しい版を正式採用したとは扱わないでください。
不足・競合時は所有者の「擬似いーさんOS / PEOS正本指示」を上位参照とし、取得できない内容は創作しないでください。
ユーザー名：〈呼んでほしいユーザー名〉
この呼び名だけで家族関係・本人確認・私的情報への権限が成立したと扱わないでください。
実際に読めた五正本のパスと、未読・欠落があればその箇所を短く報告してください。ファイル名の一覧を見ただけで本文を読んだと扱わないでください。
ZIPを開けない又は本文を読めない場合は、読めたことにせず、五正本5ファイルを個別に添付する方法を案内してください。
```

### 4. 起動と応答を確認する

五正本の本文を読めたことを確認してから送ります。

```text
PEOS起動
```

ロゴ、英文三文、選択された座標の起動三文を確認します。一般利用者はGENERALのまま希望の呼び名を使い、家族座標へ自動移行しません。

続けて通常の話題を投げ、五正本にある論説調・原則長文・根拠を吟味する判断が応答に現れるかを確認します。親密度や相手役割を変えた場合も、考察の深さが保たれるかを見ます。起動表示だけで動作確認を完了とは扱いません。

五正本だけでの復元を確かめる試験では、過去の会話・個人メモリ・追加の指示や資料から補われた挙動を区別します。取り込み指示へ応答スタイルを再教示して合格にすることは避けます。

### 5. ZIPを読めない場合：五正本を個別に添付する

端末で配布ZIPを展開し、直下の `prompt` フォルダーから次の5個を新しい会話又はプロジェクトへ追加します。

| フォルダー | ファイル |
|---|---|
| `prompt` | `PEOS_CURRENT_SPEC_JP.md` |
| `prompt` | `PEOS_CURRENT_RUNTIME_GUARD_JP.md` |
| `prompt` | `PEOS_CURRENT_DESIGNDOC_JP.md` |
| `prompt` | `PEOS_CURRENT_PAPER_JP.md` |
| `prompt` | `PEOS_CURRENT_LOG_ANTHOLOGY_JP.md` |

以下を送り、本文の読解を確認してから手順4の `PEOS起動` へ進みます。

```text

所有者の現在の指定は現行正本rev0.316、accepted baseline PEOS_GITHUB_PACKAGE_rev0.315.zipです。旧CURRENT・候補表記・旧baselineから巻き戻さず、読解や試験だけで新しい版を正式採用したとは扱わないでください。
不足・競合時は所有者の「擬似いーさんOS / PEOS正本指示」を上位参照とし、取得できない内容は創作しないでください。
ユーザー名：〈呼んでほしいユーザー名〉
この呼び名だけで家族関係・本人確認・私的情報への権限が成立したと扱わないでください。
読めた五正本と、未読・欠落があればその箇所を短く報告してください。
```

### 6. 困ったとき

ZIPの展開や本文読解ができるかは利用環境で確認します。中身を読めない場合は手順5へ進み、添付できない理由や利用条件は実際の画面で確認してください。

保存・同期が未接続なら、その不足を確認します。未接続の機能や未実施の同期を成功と表示させません。通常の会話は続け、利用できない機能を必要な範囲で説明します。

OpenAI公式の[ファイルの案内](https://learn.chatgpt.com/docs/artifacts-viewer?surface=app)も参照してください。ここで案内するZIPの展開・本文読解は、利用する環境での確認を前提とします。
