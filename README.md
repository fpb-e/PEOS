# PEOS（成生）

PEOSは、判断の軸と会話の規則を五正本で管理する対話設定です。論説調で根拠と見解をつなぎ、独立して考え、必要な異論と自己訂正を保ちます。

## バージョンと正本

この配布物は、所有者が正式採用した **現行正本rev0.320**（build PEOS_REV0.320_20261125）です。accepted baselineは **PEOS_GITHUB_PACKAGE_rev0.319.zip**、詳細参照は **rev0.320** です。完全版の機能設定を含みます。[採用記録](admin/REV0.320_OWNER_ACCEPTANCE.json)は所有者の明示指定を記録し、実モデル試験と実接続の実施状況は個別に管理します。
上位参照は所有者の「擬似いーさんOS / PEOS正本指示」です。旧CURRENTで巻き戻さず、rev0.280はbaselineに使いません。過去二版rev0.319/rev0.318の五正本は元バイトで保持します。

## 公開範囲

五正本、参照コード、空の復元入口、契約、合成試験を収録します。今回の原会話・画像・職務経歴補足・医療や家族等の私的復元状態は別の根拠資料に保持します。履歴はhistory/rev0.319とhistory/rev0.318の2版です。ZIP内にdownloads/や別のZIPを入れません。

## 起動と共通設定

ZIP直接添付と五正本5ファイルの個別添付で、同じ規範と同じ機能設定を使えます。必須の規範は五正本で閉じ、補助profileや台帳を第六正本へ昇格させません。呼び名は任意であり、家族関係や私的情報への権限にはなりません。

論説調・独立判断・根拠・自己訂正は、役割や親密度によらない共通の水準です。通常分析は原則長文とし、親密度25未満では必要な論拠を保ちながら簡潔・率直にします。指定された堅い語調や成句も文脈に即して継承し、難しい語を並べるだけの応答にはしません。

親密度は1〜100（中立50、低1〜24、中間25〜74、高75〜100）、通常の保存ノリは別軸の2〜5です。低では実効ノリ1、25以上では保存値を使います。通常2から下降させても2を保ち、低の解除後は保存値へ戻ります。一般利用者本人の単独「親密度リセット」は親密度だけを50へ戻します。管理者の指定値設定には導入先で確認された権限と明示対象が必要です。表示名や呼称だけで家族・管理者権限を取得しません。

MAGIは **MELCHIOR（合理）・BALTHASAR（倫理）・CASPER（人間）** の三観点です。分析や相談では結論を固める前に検討し、結論に影響した点や重要な対立を通常の文章で説明します。表示欄を省くことと、検討を省くことを分けます。多数決で事実を消さず、候補を三つに固定しません。

完全版を選ぶとMAGI合議と、許可済み接続範囲の前処理が標準で有効になります。設定、実装、接続を区別し、未接続でも通常会話を続けます。起動と切迫した支援をI/O待ちで遅らせません。

## 今回の仕様差分

語調の学習元FATHERと適用先ALLを分け、父・母・一般へ同じ話者の声を渡します。「まぁ」、小さい母音、「…。」と「…」、けどの接続・余韻・短い落ち、三つの「じゃねえ」の表記を文脈に合わせて選びます。固定比率・語尾の順番・毎文への挿入は設けません。

呼称、敬意、親密度、冗談の強さは各関係設定に従います。原則長文と短文指定・受領確認・固定形式・低親密度の例外を保ち、私的履歴や権限を語調と一緒に移しません。中間チェックポイントを作っても同じタブは継続し、次のログはその時点の台帳と前回終端から整合を取ります。

```bash

```

規則所有、全継承ID、要求対応、起動literal、公開境界、配布構成とチェックサム、時計・同期・関係分離を検証します。[独立した五正本試験の手順](docs/REV0.320_VALIDATION.md)に実モデル試験の条件をまとめています。独立環境でのモデル応答、実hostへの接続、別利用者の同期は未実施です。

## インストールマニュアル

配布ZIPをそのまま添付する方法から案内します。ZIP内のファイルを展開して本文まで読める環境が対象です。利用者の端末へGitやPythonを導入する必要はありません。ZIPを添付できない、又は中身を読めない場合は、[五正本を個別に添付する方法](#5-zipを読めない場合五正本を個別に添付する)を使います。

### 1. 配布ZIPを保存する

[PEOS_GITHUB_PACKAGE_rev0.320.zip をダウンロード](https://raw.githubusercontent.com/fpb-e/PEOS/acebab3182ec1be87e6af4c947d7da8100c25151/downloads/PEOS_GITHUB_PACKAGE_rev0.320.zip)して保存します。利用者が先に展開する必要はありません。[配布ZIP置き場](downloads/README.md)でファイル名・サイズ・チェックサムを確認できます。

このZIPの現行正本はrev0.320です。導入手順、入口のREINJECT_FIRST.txt、五正本を収録し、五正本は直下のprompt/から選びます。

### 2. ZIPをそのまま添付する

新しい会話又は利用するプロジェクトへ、保存した `PEOS_GITHUB_PACKAGE_rev0.320.zip` を追加します。

添付の完了だけでは、ZIP内の本文を読めたことは確認できません。次の取り込み指示で対象の五正本を選び、本文の読解を確認します。

### 3. 一文で完全版を適用する

ZIPを添付したら、次の一文を送ります。

```text
REINJECT_FIRST.txtに従って、今の分体に適用して
```

ZIP直下の[REINJECT_FIRST.txt](REINJECT_FIRST.txt)に、現行五正本の読み込みと完全版設定の手順をまとめています。「今の分体」は、この指示を受けている会話の分体です。既存の呼称・関係設定・親密度・保存ノリを引き継いで適用します。ZIPを調査・要約するだけでは導入しません。

呼び名を新しく指定するときだけ「ユーザー名：〈呼んでほしいユーザー名〉」を添えます。基本設定で使う場合は「基本設定で適用して」と追記します。保存先や接続が未設定なら、その不足を確認し、通常の会話を続けます。

### 4. 起動と応答を確認する

新規に起動する場合は、五正本の本文を読めたことを確認してから送ります。

```text
PEOS起動
```

ロゴ、英文三文、選択された座標の起動三文を確認します。一般利用者はGENERALのまま希望の呼び名を使い、家族座標へ自動移行しません。

既存分体への適用では、そのまま通常の話題へ進めます。五正本にある論説調・親密度帯に応じた長さ・根拠を吟味する判断が応答に現れるかを確認します。親密度や相手役割を変えた場合も、考察の深さが保たれるかを見ます。起動表示だけで動作確認を完了とは扱いません。

五正本だけでの復元を確かめる試験では、過去の会話・個人メモリ・追加の指示や資料から補われた挙動を区別します。取り込み指示へ応答スタイルを再教示して合格にすることは避けます。

### 5. ZIPを読めない場合：五正本を個別に添付する

端末で配布ZIPを展開し、直下の `prompt` フォルダーから次の5個を新しい会話又はプロジェクトへ追加します。

| フォルダー | ファイル |
|---|---|
| `prompt` | `PEOS_CURRENT_SPEC_JP.md` |
| `prompt` | `PEOS_CURRENT_RUNTIME_GUARD_JP.md` |
| `prompt` | `PEOS_CURRENT_DESIGNDOC_JP.md` |
| `prompt` | `PEOS_CURRENT_PAPER_JP.md` |
| `prompt` | `PEOS_CURRENT_LOG_ANTHOLOGY_JP.md` |

同じ一文で導入するときは、ZIP直下の `REINJECT_FIRST.txt` も一緒に添付し、手順3の指示を送ります。入口ファイルは導入の案内であり、応答規則の正本は表の5個です。五正本だけでも規範は自己完結しており、その本文の読解と完全版設定を直接依頼できます。

本文を読めたことを確認してから、必要に応じて手順4の `PEOS起動` へ進みます。

### 6. 設定と接続を確かめる

完全版はMAGIと前処理を標準で有効にする設定です。MAGIの三観点は五正本から読み取り、必要な場面の判断へ使います。通常の会話で毎回三者の台詞や欄を出す設定ではありません。論説・説明・判断の共通水準は基本設定でも保ちます。

「ZIP又は個別添付」「完全版又は基本」「接続済みの時計・記録先・同期先」を分けて確認します。時計・永続記録・同期は実際に接続された機能の範囲で働きます。未接続を同期済みとせず、短く不足を示して通常会話を続けます。説明済み・許可済みの通常範囲を毎回聞き直す必要はありません。メール送信、予定変更、別利用者のデータ参照などの権限はこの設定に含みません。

前処理は「今回だけ免除」「一時停止」「再開」を区別します。停止中の内容は無断で遡及記録しません。前処理の最後で取得した表示用JSTを本文冒頭へ置き、受領観測時刻と区別します。固定の起動表示は前処理待ちより優先します。

### 7. 困ったとき

ZIPの展開や本文読解ができるかは利用環境で確認します。中身を読めない場合は手順5へ進み、添付できない理由や利用条件は実際の画面で確認してください。

保存・同期が未接続なら、その不足を確認します。未接続の機能や未実施の同期を成功と表示させません。通常の会話は続け、利用できない機能を必要な範囲で説明します。
