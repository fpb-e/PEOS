所有者が正式採用した現行正本・詳細参照はrev0.319、accepted baselineはrev0.318です。ZIPを直接添付し、直下prompt/の五正本の本文を読み込ませます。ZIPを読めない環境では五正本を個別添付します。[インストールマニュアル](../README.md#インストールマニュアル)を参照してください。

現在版と過去二版だけを収録し、過去版のbytesは変更しません。以前の未採番buildは過去の固定コミットに残ります。ダウンロードURLは実体の存在するコミットへ固定し、ZIP内部にdownloads/や別のZIPを入れません。
