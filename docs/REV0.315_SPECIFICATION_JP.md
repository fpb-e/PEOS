# rev0.315 仕様化

現行正本rev0.314、accepted baseline PEOS_GITHUB_PACKAGE_rev0.313.zip、詳細参照rev0.314を維持する未受入候補。最新65 user turn・回収済みassistant15event・画像12枚を根拠とし、前半assistantとT061初期commentaryの欠落は補わない。

18要求を五正本の一意ownerへ統合し、旧412規則を削除せず430規則とした。COREの論説調・文脈的な芝・軽い呆れの♨️・自己懐疑は全座標に共通。PREは利用者別のnamespaceと実行証拠を要求する。DISTは五正本5添付、任意の呼び名、README後半のマニュアルを保つ。

呼び名は表示上の希望であり、家族座標・本人認証・私的状態の権限ではない。一般利用者が家族的な呼び名を選んでもGENERALのまま、父の学習原文や他利用者のjournalへアクセスしない。一般利用者の明示的学習差分は本人namespaceと原文spanを確認して記録し、父corpusへ混ぜない。

匿名投稿と人物経験、保護動物の経緯、採用選考結果、面接向けの思想表現は、公開正本には一般化した状態・証拠の規則だけを置く。具体的な本人説明と最新状態は私的根拠資料へ保持する。原文と導出要求と公開一般化を同一視しない。

PUBLICは会話・画像・実file ID・私的restoreを含めない。履歴は314/313だけを保持し、五正本の元bytesは変更しない。元314の内部にあるcandidate/current表示はbuild snapshotであり、後続の父の権威指定が優先する。

短縮前処理の既存契約を継承する。ACKとreadback、合成試験とlive同期、コードと実モデル応答を分ける。今回の仕様化はGitHubへのcommit・merge、送信、予約、自動化の再開又はprivate台帳操作を行わない。

受入は未実施。公開validatorは規則所有、18要求の正本対応、5添付導入、公開境界、履歴hash、manifestと負例・合成実装試験を検査する。複数モデルの同一課題比較と利用者ごとの実sync受入は別工程である。
