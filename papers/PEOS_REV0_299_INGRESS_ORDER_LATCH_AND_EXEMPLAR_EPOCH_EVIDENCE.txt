[INGRESS_ORDER_LATCH]
turn arrival後の第一実行行為がcanonical Python capture attemptであったかをimmutable latchとして保持する。

VALID:
  FIRST_EXECUTABLE_ACTION == Python datetime.now(ZoneInfo("Asia/Tokyo")) attempt
INVALID:
  any other executable action occurs first

一度INVALIDになったTURNは後続Python/shell/UI/assistant時刻によってVALIDへ戻せない。late captureは別eventの観測値としてのみ保存する。

[HARD-GATE CONTROL]
INGRESS_ORDER_LATCH == FALSE の場合:
- full requested workを開始しない
- file inspection / format inspection / artifact build / memory mutation / package mutation / web / connector / image workを通常経路で継続しない
- 許可するのはtyped incident receiptと、必要最小限のfailure reportだけ
- `PASS_WITH_DISCLOSED_LIMITATION`でoperative acceptanceへ進めない

[CANONICAL FIELD SCHEMA]

provider / attempts / success-index / capture-order / gate-validityは同一trust classへ伝播する。

JST-only current-output policyにより、WIB等の中間timezoneを通常成果物のcanonical time metadataへ出さない。
